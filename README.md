# San Luis Grocery Store Website

A static website I built for the grocery store I managed. It includes a home page, food menu, grocery selection, meat and produce pages, and information about the family-owned store in Kenosha, Wisconsin.

## Built with

HTML and CSS, with a small JavaScript welcome message on the home page.

## Pages

- `home.html`: store introduction, business hours, and location.
- `foodmenu.html`: food menu.
- `groceries.html`: grocery products.
- `meat.html`: meat department.
- `produce.html`: produce section.
- `aboutUs.html`: store background.

## View locally

Download or clone this repository, then open `home.html` in a browser. Keep the HTML, CSS, and image files together so the links and images load correctly. No database or build step is needed.

## Status

Portfolio website. Business details and prices reflect the original project and may no longer be current. This repository is a code sample rather than the store's official website.
